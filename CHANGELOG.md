# Changelog

## 1.0.0 - Release candidate

- Added the CCEAD TinyMCE font-size control with sizes from 8 pt to 36 pt.
- Added capability checks, privacy metadata, PHPUnit coverage, AMD source, and compiled AMD artifacts.
- Declared Moodle 5.1 and 5.2 support and tested PostgreSQL and MariaDB combinations in GitHub Actions.
- Kept the plugin independently installable from `tiny_cceadfontfamily`.
